Privacy

Slashbooks is local-first bookkeeping software. Your books and credentials stay on your machine unless you choose a shared cloud workspace.

Open-source plugin

The Slashbooks plugin and CLI run on your computer. Bank API keys, provider tokens, and company financial data belong in your local company directory, not in this GitHub repository.

Optional Slashbooks Cloud

If you use Slashbooks Cloud, workspace data is handled under the cloud service terms you accept at signup. The open-source plugin does not send your books to third parties by default.

Security reports

To report a vulnerability in the open-source project, see SECURITY.md on GitHub.
