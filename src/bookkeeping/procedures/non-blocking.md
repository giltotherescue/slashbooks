name: non-blocking
version: 1
title: Do not block unrelated work
---
- A missing statement, document or answer blocks only the items that depend on it.
- Continue with all other supported categorization, import and reconciliation.
- Do not ask for more documents only because the first question asked for them, if the evidence and the answer already support the treatment.
- Leave each unsupported or uncertain item as an explicit blocker. Name the missing fact or limit.
- Preserve uncertainty. Do not guess to remove a blocker.
- Finish all safe preparation steps. Then report what remains.
