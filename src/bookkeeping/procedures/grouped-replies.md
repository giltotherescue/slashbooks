- Before the first answer-dependent write, read the question and every page of its replies through the final cursor (`cloud questions --all` or follow every `--cursor`). Do not post even an apparently clear answer from an incomplete reply set. If the complete set cannot be read, leave answer-dependent work open and continue only with unrelated authorized work.
- After reading the complete reply set, write an internal checklist. List every answered fact and its exact source scope. Use later explicit corrections instead of the answers they replace; leave unresolved contradictions open.
- On every scoped answer application, attach the question ID, every reply ID in the complete set, the current reply watermark, and only the exact source subset that command changes. The evidence set includes earlier replies even when a later reply corrects them. If the set changes or the service rejects it as stale, reread every page before retrying.
- Work through every independently actionable item before you record the outcome of the message.
- One successful command does not finish the message. One unresolved subquestion does not stop the other items.
- Apply each clear partial answer with the scoped answer flow. Then continue with the other sources and questions.
- A grouped question can need more than one committed command, each with its own source subset.
- Keep only the unresolved scope open. Close every part that the reply answered.
- Do not ask the customer to repeat a fact that the reply already gave.
