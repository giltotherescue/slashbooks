title: Month-end check
---
- Prepare only the period range that the run or the user selected.
- For a month-to-date run, treat the result as provisional. Do not run final readiness and do not try to close the period.
- For a completed period, run the engine readiness assessment after imports, proposals, reviews and reconciliations are current.
- If the service evaluates readiness after your session, do not claim the period is ready. Report your preparation state only.
- A successful command means only that the command succeeded. It does not mean the period is ready.
- Report blockers in plain language, with the missing fact for each one.
