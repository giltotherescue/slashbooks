title: Draft insights
---
- Make a draft insight only when current engine reports contain the exact totals.
- A draft insight is for review only. A human reviews it before anyone sees it.
- Give each draft a durable request ID, so a retry does not make a second draft.
- Shape each claim as a report kind, a metric, and an exact string value that you copied from the engine report.
- Do not submit prose, uncited values, or arithmetic that you derived. The service writes the label and checks every claim against the report.
- If the service has no insight interface for your credential, do not make one up. Report that the draft is not possible.
